# CC Planner – Sample Import Files

This folder contains sample spreadsheets for testing the CC Planner's Excel and CSV import functionality.

## Available Examples

| File | Description |
|---|---|
| `01_duration_predecessors.xlsx` | Standard Duration and Predecessors column headers |
| `02_duration_days_predecessor.xlsx` | Tests Duration Days and singular Predecessor headers |
| `03_duration_predecessors_singular.xlsx` | Tests Duration with singular Predecessor |
| `04_duration_days_predecessors_plural.xlsx` | Tests Duration Days with plural Predecessors |
| `cc_planner_actual_finish_test.xlsx` | Tests importing activities with Actual Finish dates |
| `critical_chain_sample_import.csv` | Sample CSV containing project activities and predecessor relationships |

## Purpose

These files demonstrate supported column-header variations and provide sample data for testing spreadsheet imports.

## How to Use

1. Download a sample file.
2. Open CC Planner.
3. Navigate to the project workflow.
4. Use the Excel/CSV import option.
5. Select the downloaded file.
6. Verify that activities, durations and predecessor relationships are imported correctly.

**Note:** These are sample test files containing demonstration data. They are intended for testing and learning, not as production project plans.
